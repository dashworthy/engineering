# Committed specs — ledger index

This is the durable, browsable record of the specs this project has approved — kept so past specs
can be read, compared, and learned from long after the work that produced them is done. Each piece
of work runs through the engineering pipeline as a dated **run** (e.g. `2026-09-11-commit-specs-retro`);
when its spec is approved, a frozen copy of that spec is committed here and listed below, newest
first.

Each row links the run's `spec.md` (the frozen approved snapshot) and its `retro.md` (a companion
written when the work ships, recording how the finished work compared to the spec). `Shipped` reads
`—` until the run ships. Rows are added by the pipeline automatically — you don't edit this file by
hand; the row format is defined in `../../skills/spec/references/SPECS-TOC-FORMAT.md`. This is a
separate index from the feature-doc table of contents at `../toc.md`.
